# Visual Audit — 2026-08-28 (스타일 개편 전 현황)

전 화면 직접 플레이 후 작성. 점수는 1~5 (4 미만 = 개선 대상).

## 화면별 진단

| 화면 | 현재 상태 | Commercial feel |
|---|---|---|
| 운영 씬 (핵심) | 전부 procedural canvas 사각형. 벽 텍스처 없음, 배경 스카이라인은 회색 블록, 재질 구분 없음, 소품 없음 | **1.5** |
| 상권 조사 | 카드 안 canvas 일러스트가 flat rect + 점 사람. "서울"이 글자로만 존재 | **2** |
| 집기/원두/메뉴 카드 | 도트 일러스트는 있으나 재질감 없음, placeholder 느낌 | **2.5** |
| 미니게임 3종 | 구조는 좋으나 배경이 단색 그라데이션 + 선 | **2.5** |
| 마감 리포트 | 타이포는 정돈됐으나 SaaS 대시보드 느낌, 원장/영수증 메타포 없음 | **3** |
| 랜딩 | 히어로 캔버스가 도트 스타일로 가장 완성도 높음 | **3.5** |

## 공통 문제 (지시서의 DO NOT USE 위반 항목)

1. **primitive canvas drawings** — 운영 씬·상권 일러스트 전부
2. **재질 부재** — 벽돌/스테인리스/유리/나무 구분이 색상 하나로만
3. **깊이 부재** — BACKGROUND/MIDGROUND/FOREGROUND 레이어 없음 (운영 씬은 있으나 각 레이어가 빈약)
4. **서울 정체성 부재** — 상권명이 텍스트로만; 성수 벽돌창고/을지로 골목이 안 보임
5. **살아있는 느낌 부족** — 손님 이동은 있으나 마이크로 애니메이션(문·영수증·조명 깜빡임) 희박

## 결론

핵심 병목 = **운영 씬 배경이 코드로 그린 사각형**이라는 점.
백플레이트를 일러스트 에셋으로 교체하고 동적 요소(손님·직원·스팀·간판 텍스트·조명)만
캔버스로 얹으면 화면당 최대 레버리지. → art bible 참조.
