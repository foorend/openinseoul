# OPEN IN SEOUL 개선 · 단계별 검수

## 사용성 후속 개선 · 2026-10-06 (최신 작업)

- 운영: 장면에서 조작부를 분리. PC는 장면 옆 상세 관리 스크롤, 모바일은 하단 고정 버튼과 매장/관리 탭. DOM을 재배치해 기존 입력·장부 계산을 재사용했다.
- 첫 연습: 실제 엔진의 고정 1인 카페 샘플에서 홀 정리→첫 주문 제공→매출/노동 해석. 본게임 장부와 분리. 빠르게 관찰하기는 같은 엔진 시간을 진행하며 결과 수치를 직접 만들지 않는다.
- 리포트: 일 이익·노동, 월 이익·노동·현금 우선. 원장·나머지 지표는 접기, 진행 버튼은 하단 고정. 연말 상세 지표와 엔딩은 보존.
- 코치/실험: 실제 메뉴 이탈→메뉴 교체 가설. 인지 이탈→인지율을 고정한 영업시간 비교라는 한계를 표시. 메뉴 한 개만 교체하며 업태/설비/납품 2종 제한을 검사한다.
- 결정 미션: 실제 예상·계산 결과·해석·적용/유지 기록. 비교나 정답 선택만으로 완료하지 않는다. 월이 달라지면 이전 작성 중 결과를 표시하지 않는다.
- 자동 검사: 문법 검사와 47개 테스트 통과. 기존 44개 회귀검사에 첫 연습 실제 주문·노동, 메뉴 비교 재현/본게임 불변, 설비·납품 제한을 추가.
- 개발자 브라우저: quick 개업→연습→1월 평일/주말→메뉴 비교(예상 up, 결과 down)→잘못된 해석 잠금→적용 예약→새로고침 복원→4월 실제 교체→9월→12개월 연말 결산. 비교만 했을 때 완료 기록 없음, 최종 결정 1개 보존. 이 실행의 세후 현금 7,174.083775614677만원.
- 레이아웃 실측: 독립 CSS viewport 320×844/390×844에서 바깥 가로 넘침 0, 매장 하단 y660·조작부 y672–844, 속도 버튼 44px·자리 버튼 46px. PC1366×768에서 매장 하단 y758. 스크린샷을 직접 확인했다.
- 독립 로컬 게이트 PASS (`ffdaab0` + `a39e642`, `release=20261006c`). 예상/잘못된 해석/유지/적용/새로고침을 각각 검수했고, 비교만으로 미션이 완료되지 않으며 실험 중 본게임 exportState가 불변이었다. 월 현금 대사 최대 오차 7.4e-11만원, 연말↔12월↔새로고침의 현금 불변, 47/47 테스트·문법·diff 검사·pageerror 0.
- 검수에서 발견한 320px 금액 분절은 한 줄 금액의 단일 열 카드로 해결. 일시정지 복원의 속도 표시, PC 관리 카드 잘림도 해결. 작은 화면의 돌발 상황은 매장과 분리된 native dialog로 표시한다. 관리 탭에서 QA로 발생시킨 rush_hour의 선택지가 전부 보이고, 실제 쿠키 선택 후 현금 정확히 −4만원·대화창 닫힘·시계 재개 확인. 연습 보조 버튼도 44px 이상.
- 실제 휴대폰 하드웨어·Safari 터치/키보드 장시간 홀드·30명 교육효과 검증은 이번 브라우저 검수로 대체하지 않는다. 공개 HTTPS 스모크 검수는 배포 후 별도 기록한다.
