# OPEN IN SEOUL 개선 · 단계별 검수

목표: 창업 결정 → 실제 운영 → 현금·손익·노동 근거 → 한 조건 재실험을 15–30분 브라우저 체험으로 완성한다. 모두의창업 신청서의 출처 표시, 근거 코치, 익명 교육 파일럿까지 연결한다.

| 단계 | 통과 기준 | 상태 |
| --- | --- | --- |
| 0 | 코드·공개판·신청서 비교, 사용자 변경 보존, 독립 검수자 지정 | PASS |
| 1 | 노동시간·수수료·일회지출 정확성, 월/연 현금 대사 | PASS · 38 tests · 검수자 재현 |
| 2 | 진행 저장·복원, 동일 seed/버전 한 조건 실험 | PASS · 41 tests · 브라우저 복원/다음달 적용 재현 |
| 3 | 간편 개업, 병목 중심 운영, 가독성/터치 관리, 3챕터·12개월 | PASS · 41 tests · 독립 320px/3챕터 완주·현금 대사 |
| 4 | 실제 기준/합성 가정 구분, 출처·연도·버전·변환 규칙 | PASS · 42 tests · 원문/실제 표본·390px·구버전 JSON 보존 검수 |
| 5 | 계산 근거 3개 코치 카드·미션, 생성 연결 실패 시 fallback | PASS · 43 tests · 390px 미션/적용·동일 조건 재도전·중복 방지 검수 |
| 6 | 익명 교육 코드·사전후 이해도·완주/재실험·강사 CSV | PASS · 44 tests · 실제 파일/CSV·중복병합·사전후 분리·390px·재도전/복원 검수 |
| 7 | 실제 브라우저 클릭·복원·실험·결산·모바일 검수, HTTPS 배포 | 대기 |

검수자는 각 단계에서 PASS/BLOCK과 실행 증거를 보고한다. BLOCK을 해결하고 PASS를 확인해야 다음 단계 구현을 시작한다. 잘못된 계산에 맞춰 테스트 기대값을 바꾸지 않는다.

기존 index.html 메타데이터·아이콘과 로고는 보존한다. 주제품 웹판만 개선한다. 실사용자 30명 파일럿과 실제 교육효과 달성은 모집 후 측정할 목표이며 개발 완료로 주장하지 않는다.
